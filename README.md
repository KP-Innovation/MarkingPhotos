# ป้ายเลขที่งาน (MarkingPhotos)

เว็บแอปมือถือสำหรับถ่ายรูปตัวอย่างทดสอบ **พร้อมป้ายเลขที่งานในภาพเดียว**
แทนการวางป้ายจริงตอนถ่าย — ต่อยอดจากโปรแกรมพีซี `PlateStamper`

รหัสเป็นรูปแบบ `XX-YYMM-NNNN`
`XX` = ประเภทงานทดสอบ · `YY` = ปี · `MM` = เดือน · `NNNN` = ลำดับงานในเดือนนั้น

**พิมพ์ทั้งก้อนไปเลย** เช่น `LP-2609-0045` ไม่ต้องแยกช่อง แอปแกะให้เอง
พิมพ์ติดกันแบบ `LP26090045` ก็ได้ เดี๋ยวเติมขีดให้
ถ้าผิดรูปแบบ (ไม่มีขีด / เลขไม่ครบ) จะเตือนใต้ช่อง แต่ยังถ่ายต่อได้ ไม่บล็อก

## ชื่อไฟล์

`เลขงาน` + `ประเภทรูป` เช่น `LP-2609-0045_Front-Ruler.jpg`
ประเภทรูปเลือกจากปุ่มในหน้าตรวจรูป แตะซ้ำที่ปุ่มเดิม = ยกเลิก แล้วได้ `LP-2609-0045.jpg` เฉย ๆ

ประเภทที่มี: `Front` · `Front-Ruler` · `Rear-Ruler` · `Horizental-Side` · `Vertical-Ruler`
(แก้รายการได้ที่ตัวแปร `PHOTO_TYPES` บนสุดของ `js/app.js`)

> **หมายเหตุสำคัญ:** ชื่อไฟล์นี้ใช้ได้จริงบน Android และเครื่องคอม
> แต่ **iOS Photos ไม่เก็บชื่อไฟล์** พอเซฟเข้าอัลบั้มชื่อจะหาย เหลือแค่ป้ายที่ฝังอยู่ในรูป
> ถ้าต้องการชื่อไฟล์จริง ๆ บน iPhone ให้เลือก "Save to Files" แทน "Save Image"

## ป้ายอยู่ตรงไหน — เลือกได้ 2 แบบ

| แบบ | หน้าตา | เหมาะกับ |
|---|---|---|
| **ป้ายใต้ภาพ** *(ค่าตั้งต้น)* | ต่อแถบพื้นเข้มใต้รูป แล้ววางป้ายกลางแถบ **รูปไม่ถูกป้ายบังเลยสักพิกเซล** | งานทั่วไป — ไม่ต้องกะระยะหลบป้ายตอนถ่าย |
| **ป้ายในภาพ** | ป้ายทับอยู่บนรูปแบบโปรแกรมพีซี ลากย้าย/ย่อขยายได้ มีปุ่มหาที่ว่างอัตโนมัติ | เวลาต้องการให้ป้ายอยู่ในเฟรมรูปจริง ๆ |

สไลเดอร์เดียวกันคุมคนละอย่างในสองแบบ: แบบแถบคุม **ความสูงแถบ** (6–28% ของความสูงรูป
วัดจากความสูงเสมอ รูปตั้งกับรูปนอนจึงได้แถบหนาเท่ากัน) แบบทับภาพคุม **ความกว้างป้าย** เหมือนเดิม

## สองโหมดกล้อง

| โหมด | ได้อะไร | เสียอะไร |
|---|---|---|
| **กล้องสด** | เห็นภาพเต็มมุมมองพร้อมแถบป้ายตั้งแต่ตอนเล็ง ได้อะไรเห็นอย่างนั้น | ภาพมาจากสตรีมวิดีโอ ไม่ผ่าน Smart HDR / Deep Fusion จึงคมน้อยกว่าแอปกล้องของเครื่อง |
| **กล้องเครื่อง** | เรียกแอปกล้องของเครื่อง ได้คุณภาพเต็ม | ไม่เห็นป้ายตอนถ่าย ต้องมาวางทีหลัง |

ทั้งสองโหมดจบที่หน้าเดียวกัน สลับแบบป้ายและปรับขนาดได้จนกว่าจะกดบันทึก
โปรแกรมจำรหัส แบบป้าย ตำแหน่ง และขนาดล่าสุดไว้ให้

### มุมมองกล้องสดต้องเท่ากล้องหลักของเครื่อง

เวอร์ชันแรกขอสตรีม 3840×2160 (16:9) ทั้งที่เซนเซอร์มือถือเป็น 4:3 เบราว์เซอร์จึงครอปบน-ล่างทิ้ง 25%
แล้วโค้ดยังครอปเป็นจัตุรัสซ้ำอีกชั้น เหลือมุมมองแนวนอนแค่ ~56% — เหมือนซูมค้างไว้เกือบ 2 เท่า
ต้องถอยห่างกว่าใช้แอปกล้องปกติ ตอนนี้แก้เป็น:

- ขอ **4032×3024 (4:3) + `resizeMode: none`** ไม่ให้เบราว์เซอร์ครอป/ย่อเอง
- **กรอบพรีวิวยึดสัดส่วนจริงของสตรีม** ไม่ฮาร์ดโค้ด 1:1 อีกแล้ว
- **เก็บภาพเต็มเฟรม** ครอปเฉพาะตอนซูมดิจิทัล และครอปโดยรักษาสัดส่วนเดิม
- ใต้กรอบมีบรรทัดบอก **ขนาด/สัดส่วนที่กล้องส่งมาจริง** เช่น `4032×3024 (4:3)`
  ถ้าเครื่องไหนขึ้น `16:9` แปลว่ารุ่นนั้นไม่มีโหมด 4:3 ให้เว็บใช้ จะได้รู้ทันทีว่ามุมมองหายเพราะอะไร

## ข้อจำกัดที่แก้ไม่ได้ (เป็นข้อจำกัดของ iOS ไม่ใช่ของโค้ด)

- **บันทึกลงอัลบั้มอัตโนมัติไม่ได้บน iPhone** — เว็บไม่มีสิทธิ์เขียนลง Photos โดยตรง
  แอปจะเปิด share sheet ให้ ต้องแตะ **"Save Image"** อีกหนึ่งครั้ง
  บน Android ไฟล์จะลงโฟลเดอร์ดาวน์โหลดและโผล่ในแกลเลอรีเอง
- **ซูมออปติคอลและปรับ exposure จริงใช้ไม่ได้บน Safari iOS** — แอปตรวจความสามารถของกล้องเอง
  ถ้าเครื่องรองรับ (ส่วนใหญ่คือ Android) จะสั่งฮาร์ดแวร์ตรง ๆ
  ถ้าไม่รองรับจะสลับเป็นแบบดิจิทัลและเขียนกำกับไว้ว่า "(ดิจิทัล)"
- ต้องเปิดผ่าน **HTTPS** เท่านั้น กล้องจึงจะทำงาน (localhost ก็ได้ตอนพัฒนา)

## ติดตั้งบนมือถือ

เปิด URL ในเบราว์เซอร์ → แชร์ → **Add to Home Screen** → ได้ไอคอนแอปเหมือนแอปทั่วไป
กล้องใช้งานได้ในโหมด standalone (iOS 14.3 ขึ้นไป)

## โครงไฟล์

```
index.html              3 หน้าจอ: กรอกรหัส / กล้องสด / ตรวจรูป
style.css               .shot = ภาพ + แถบป้าย (คือสิ่งที่จะได้เป็นไฟล์), .frame = พื้นที่ภาพล้วน
js/plate.js             วาดป้ายจากรหัส — พอร์ตตรงจาก plate.py ค่าคงที่เดิมทุกตัว
js/autoplace.js         หาพื้นที่ว่างในรูป — พอร์ตจาก compose.py (subject_mask + auto_position)
                        ใช้เฉพาะแบบ "ป้ายในภาพ"
js/app.js               สถานะ กล้อง การลาก/ย่อขยายป้าย และการบันทึก
                        shotLayout() คำนวณกล่องภาพ+แถบ ใช้ร่วมกันทั้งพรีวิวและไฟล์จริง
assets/glyphs/*.png     รูปตัวอักษรจริง 37 ตัว (0-9, A-Z, dash) ยกมาจาก PlateStamper
assets/metrics.json     ความกว้าง/สูง/แนวบรรทัดของแต่ละตัวอักษร
assets/fonts/*.woff2    ฟอนต์ Anuphan (ไทย+ละติน) เก็บไว้เอง ใช้ได้ตอนออฟไลน์
sw.js                   แคชไว้ใช้ตอนสัญญาณไม่ดี
```

ป้ายไม่ได้เจนจากฟอนต์ แต่ต่อจาก **รูปตัวอักษรจริง** ที่ครอปมาจากป้ายของจริง
ป้ายที่ได้จึงหน้าตาเหมือนป้ายที่เคยวางถ่ายเป๊ะ

## ขึ้นคลาวด์ (Cloudflare Pages)

แอปนี้ประมวลผลบนเครื่องทั้งหมด เป็น static site ล้วน ไม่มี Worker ไม่มีฐานข้อมูล

1. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git
2. เลือก repo `KP-Innovation/MarkingPhotos`
3. Build command: *(เว้นว่าง)* · Build output directory: `/`
4. Deploy — ได้ HTTPS ฟรี

## รันทดสอบในเครื่อง

```bash
python -m http.server 8777
# เปิด http://127.0.0.1:8777/
```
